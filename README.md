# Mechanical Engineering Portfolio

A responsive one-page portfolio built with plain HTML, CSS, and JavaScript. No build tools or paid hosting required.

## Personalize before sharing
1. Open `index.html` in a text editor.
2. Replace `YOUR NAME`, `[Your Name]`, the sample project titles/descriptions, and skills with accurate details.
3. Replace `YOUR.EMAIL@example.com` with your professional email.
4. Update LinkedIn and GitHub links to your profiles.
5. Add a résumé PDF if you want (see the commented-out résumé link in `index.html`).

## Publish free with GitHub Pages
1. Create a GitHub account at https://github.com if needed.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`, replacing the placeholder with your GitHub username.
3. Upload `index.html` (and optionally this README) to the repository root and commit the changes.
4. In the repository, go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
6. Wait for the deployment, then visit `https://YOUR-USERNAME.github.io`.

GitHub Pages sites are public on the internet. Don't upload private, confidential, or employer-owned files. Publication can take several minutes.

## Preview locally
Double-click `index.html` to open it in your browser.
